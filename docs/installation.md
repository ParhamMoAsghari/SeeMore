# Installation

## Requirements
* Linux host with Docker Engine and the Compose plugin **v2.20+** (profiles, `include`-free single file).
* A data disk mounted at `SEEMORE_DATA` (default `/data`) with room for the library and torrents. Hard links
  between `/data/torrents` and `/data/media` need them on the same filesystem (the default layout does this).
* For USB features: systemd + udev on the host, `util-linux`, `python3`; for repairs `dosfstools exfatprogs
  ntfs-3g e2fsprogs`.
* For public HTTPS: DNS records for the panel / link (and other) domains pointing at the host, ports 80/443 open.

## Quick install
```sh
git clone https://github.com/ParhamMoAsghari/SeeMore.git /opt/seemore && cd /opt/seemore
sh install.sh                   # .env (random internal secrets), docker network, folders, permissions, Caddyfile
$EDITOR .env                 # TELEGRAM_TOKEN, ALLOWED_CHAT, JELLYFIN_PASS, domains … (every variable is documented)
sudo make host               # optional: USB auto-mount + seemore-ctl (runtime recreate / Caddy reload)
docker compose build seemore
docker compose up -d
```
(Without `make`: `sudo sh host/install.sh --all --dir "$PWD"`.)

## First start of the media services (profile `media`)
The *arr apps generate their API keys on first start. Open each UI once (SSH tunnel, e.g.
`ssh -L 7878:127.0.0.1:7878 host`, or a Caddy site), then:
1. **qBittorrent** (`:8080`): the first-start password is printed in `docker compose logs qbittorrent`; set your own
   user/password → `QBIT_USER` / `QBIT_PASS`. Default save path `/data/torrents`.
2. **Prowlarr** (`:9696`): add indexers (FlareSolverr at `http://flaresolverr:8191` for Cloudflare-protected ones),
   add Radarr and Sonarr as apps. Copy its API key → `PROWLARR_KEY`.
3. **Radarr** (`:7878`) / **Sonarr** (`:8989`): root folders `/data/media/movies` / `/data/media/tv`, download client
   qBittorrent (`qbittorrent:8080`), API keys → `RADARR_KEY` / `SONARR_KEY`. Add a *Connect → Webhook* to
   `http://seemore:3000/hook/<HOOK_KEY>` (events: grab, import/upgrade, health, health restored, manual interaction)
   and, for instant subtitles, one to `http://subfa:8090/hook/<SUBFA_HOOK_KEY>` (import/upgrade).
4. **Bazarr** (`:6767`): connect Sonarr/Radarr, a language profile with Persian, providers; API key → `BAZARR_KEY`.
5. **Jellyfin** (`:8096`): libraries `/data/media/movies` and `/data/media/tv`; the admin user/password →
   `JELLYFIN_USER` / `JELLYFIN_PASS` (also the panel owner password by default).
6. **Seerr** (`:5055`, optional request page): connect Jellyfin, Radarr, Sonarr.

Then `docker compose up -d seemore subfa` to pick up the keys. Check `docker compose ps` (seemore turns *healthy*) and
send `/start` to the bot.

## Using services you already run
Remove `media` (and/or `subfa`, `proxy`) from `COMPOSE_PROFILES` and set `RADARR_URL`, `SONARR_URL`, … to where they
are. If they run in another compose project, attach that project's containers to the `SEEMORE_NETWORK` network (or
set `SEEMORE_NETWORK` to that project's existing network). With an existing Caddy, add
`import /etc/caddy/seemore/*.caddy` to its Caddyfile, mount `state/caddy-sites` there at `/etc/caddy/seemore` (ro)
and set `CADDY_CONTAINER` (used by `seemore-ctl`).

## Panel and domains
Panel: `https://<PANEL_PUBLIC_HOST>` (or `http://<PANEL_LAN_HOST>` at home, or `http://127.0.0.1:8098` on the host),
login `PANEL_OWNER_USER` + the shared password. Open Settings → Domains and save once: seemore writes
`state/caddy-sites/seemore.caddy`, validates it and reloads Caddy (needs `seemore-ctl`). Public hosts get HTTPS
certificates automatically; LAN hosts are served over plain HTTP (point them at the host in your router's DNS or
`/etc/hosts`).

## Layout on disk
```
/opt/seemore/                    the repo (compose project dir)
  .env                           secrets + defaults (600)
  state/seemore/bot.db           seemore database (jobs, users, links, settings, sessions)
  state/subfa/                   subfa state + overrides.json
  state/caddy-sites/             site blocks generated by seemore (imported by Caddy)
  state/caddy/{data,config}      certificates
  appdata/<service>/             Jellyfin/*arr/qBittorrent/Bazarr configs
$SEEMORE_DATA (/data)            media/{movies,tv}, torrents, usb-imports, backups/seemore, dl-cache
/etc/seemore/                    ctl.conf, usb.conf (host helpers)
```

## Moving to another machine
Stop the stack, copy the repo folder (with `.env`, `state/`, `appdata/`) and `/etc/seemore`, restore the data disk
(or mount it at the same `SEEMORE_DATA`), then on the new host `sh install.sh && sudo make host && docker compose up -d`.
Change hostnames/IPs in `.env` or in the panel. See [backup-restore.md](backup-restore.md).
